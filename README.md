# Sky Dodge

Browser arcade game built with HTML5 Canvas and JavaScript.

## GitHub Pages

1. Upload the project files to the repository root.
2. Make sure `index.html` is in the repository root, not inside another folder.
3. In GitHub open **Settings -> Pages**.
4. Select **Deploy from a branch**, choose the default branch and `/ (root)`.
5. Save and wait for the Pages deployment.

Do not open the `.otf` font file as the page. It belongs in `assets/` and is loaded by `style.css`.
